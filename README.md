# AltaCoda Homebrew tap

```sh
brew install altacoda/tap/mb
```

| Formula | What |
|---|---|
| `mb` | Markbase CLI: sync your team's agent skills into Claude Code, Codex and more. [help.markbase.cloud](https://help.markbase.cloud) |

Formulas here are written by each product's release workflow. Don't edit them
by hand: the next release overwrites them. The archives they install are the
signed release archives (also served by the product's `install.sh`), and
Homebrew checks each one's sha256.

A Homebrew-installed `mb` does not update itself; run `brew upgrade mb`.
